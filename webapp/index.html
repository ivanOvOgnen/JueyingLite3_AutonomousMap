DOABLE FLOWS

Map, locate, then preview

  1. In Manual + Move, start mapping, guide one slow loop with the DEEP controller, then finish and save the 2D map.
  2. Select the saved robot map, start localization/Nav2, load that map, and click the robot's actual position to seed AMCL.
  3. With stable localization, click a known-free target, acquire session control, preview its route, enable goal requests, and submit. An unreviewed map permits only a 0.5 m supervised trial with separate arming.
A map click alone never moves the robot. The page shows the next unmet prerequisite beside disabled controls.
